# IDEAS-BACKLOG.md

Спільна скринька ідей для всіх агентів (`backender`, `mobile-dev`,
`ceo-advisor`, `product-manager`) — сюди йде все, що варто зробити пізніше,
але не пов'язане з поточною таскою настільки, щоб роздувати її гілку чи
заводити окрему дрібну задачу негайно.

Кожен агент може дописувати сюди сам. `product-manager` періодично перетворює
записи на нормалізовані задачі (`herdr task create`) і викреслює звідси.

**Не редагувати чужі записи** — тільки додавати нові й (для product-manager)
викреслювати оброблені.

## Формат запису

```
### <дата> — <короткий заголовок>
- Від: <роль>
- Тип: побажання | ідея | зауваження
- Кому: <роль, опційно>

<опис по суті>
```

### 2026-08-13 — Негарні floating-point числа в кількостях інгредієнтів каталогу
- Від: backender
- Тип: зауваження
- Кому: backender

Після t-94 (нормалізація одиниць виміру) у `GET /api/v1/recipe-catalog/{id}`
одиниця підставляється коректно, але саме число інколи лишається сирим
floating-point значенням з інджесту — наприклад
`"quantity": "0.66666668653488 cup"` замість `"0.67 cup"` чи `"2/3 cup"`.
Джерело — t-91 (міграція каталогу на `dataset_clean.csv`), не сама t-94.
Варто округлювати/нормалізувати число в `IngredientQuantityNormalizer`
(`SqliteRecipeCatalogRepository.kt`) до розумної точності (2 знаки або дріб).
